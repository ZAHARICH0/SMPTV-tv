# SMPTV

Мини-проект непрерывного вещания настроечной таблицы.

## Локальный запуск
1. Установите Python 3.10+.
2. В папке проекта выполните:
   `pip install -r requirements.txt`
3. Запустите:
   `python app.py`
4. Откройте `http://127.0.0.1:5000`.

Видео `static/smptv.mp4` рассчитано на 10 секунд и содержит тестовый тон 1 кГц.
На странице включён повтор (`loop`). Автовоспроизведение со звуком браузеры обычно запрещают,
поэтому звук можно включить кнопками плеера.

## Бесплатное размещение на Render
1. Загрузите папку проекта в новый GitHub-репозиторий.
2. В Render выберите New → Blueprint и подключите репозиторий.
3. Render прочитает `render.yaml` и создаст веб-сервис.
4. После публикации откройте выданный Render URL.

Важно: бесплатный веб-сервис Render может засыпать после периода без запросов.
Поэтому он подходит для тестового проекта, но не гарантирует круглосуточный эфир 24/7.
